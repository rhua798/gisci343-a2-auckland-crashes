This dashboard explores the spatial distribution and temporal trends of severe crashes in Auckland between 2024 and 2026.
The goal is to identify where crashes are concentrated and how their patterns change over time, helping users better understand road safety risks in the region.


2.The data used in this dashboard comes from the Waka Kotahi (NZ Transport Agency) Crash Analysis System (CAS), which provides publicly available records of road crashes across New Zealand.
